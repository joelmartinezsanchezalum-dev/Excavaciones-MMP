# MMP · Excavaciones en Rubí

Página web básica para MMP (Miguel Ángel Martínez Plazas), con servicios de excavación, nivelación de terrenos, piscinas y alquiler de una retroexcavadora.

## Cómo abrirla

Descomprime el proyecto y abre `dist/index.html` en el navegador. No hay que instalar nada. Las carpetas deben mantenerse juntas para que funcionen los estilos y las imágenes.

## Archivos principales

| Archivo | Función |
| --- | --- |
| `dist/index.html` | Contenido y estructura de la página. |
| `dist/css/styles.css` | Colores, fuentes y diseño para ordenador y móvil. |
| `dist/js/main.js` | Menú móvil, selección de servicio y formulario de prueba. |
| `dist/assets/` | Imágenes, fuentes y licencias. |
| `dist/robots.txt` y `dist/sitemap.xml` | Información básica para los buscadores. |
| `CREDITOS.md` | Procedencia de las imágenes y las fuentes. |

## Funcionamiento

La web tiene servicios, maquinaria, alquiler y contacto. El formulario permite seleccionar un servicio y simular una consulta. No envía mensajes ni realiza reservas.

El teléfono, correo, dirección y horario son ficticios. Las fotografías son de ejemplo y no muestran las máquinas de MMP.

## SEO

Siguiendo los conceptos de **B01 Introducció al SEO.pdf**, se utilizan palabras como «excavaciones en Rubí» y «alquiler de retroexcavadora», textos de enlace descriptivos y navegación interna. También se incluyen título, descripción, encabezados ordenados y textos alternativos en las imágenes.

La versión alojada inicialmente es privada; no puede posicionarse en buscadores mientras siga así. Si cambias de dominio, actualiza la URL canónica de `index.html` y las direcciones de `robots.txt` y `sitemap.xml`.

## Modificaciones

Cambia los textos y contactos en el HTML, los colores en el CSS y el comportamiento en JavaScript. Se han comprobado la sintaxis de JavaScript y los enlaces locales; no se ha realizado una revisión visual en navegador.
