# MMP · Excavaciones en Rubí

Página web básica para MMP (Miguel Ángel Martínez Plazas), una empresa ficticia de Rubí, Barcelona, dedicada a las excavaciones, la nivelación de terrenos, la preparación de piscinas y el alquiler de una retroexcavadora.

## Cómo abrir la web

Abre el archivo `index.html` en un navegador. No es necesario instalar ninguna dependencia. Para que todo funcione correctamente, mantén juntas las carpetas `assets`, `css` y `js`.

## Estructura principal

| Archivo o carpeta | Función |
| --- | --- |
| `index.html` | Estructura y contenido de la página. |
| `css/styles.css` | Colores, tipografías, diseño y adaptación a móvil. |
| `js/main.js` | Menú móvil, selección de servicios y formulario de prueba. |
| `assets/` | Imágenes, tipografías y licencias. |
| `robots.txt` | Indicaciones básicas para buscadores. |
| `sitemap.xml` | Mapa básico de la página. |
| `CREDITOS.md` | Procedencia de las imágenes y las tipografías. |

## Contenido de la web

La página presenta los servicios de MMP, su retroexcavadora y su giratoria, la opción de alquilar la retroexcavadora y un formulario de contacto de prueba.

El formulario no envía datos ni realiza reservas. El teléfono, el correo electrónico, la dirección y el horario son ficticios y se han incluido únicamente para este proyecto académico.

## SEO básico

La web incluye un título descriptivo, una meta descripción, encabezados ordenados, textos alternativos para las imágenes, enlaces internos, `robots.txt` y `sitemap.xml`. También utiliza expresiones relacionadas con el servicio y la ubicación, como «excavaciones en Rubí» y «alquiler de retroexcavadora».

## Publicación en GitHub Pages

Para publicar la página, sube a la rama `main` los archivos de la raíz del proyecto y configura GitHub Pages con la carpeta `/(root)`.

La dirección prevista para la publicación es:

`https://joelmartinezsanchezalum-dev.github.io/Excavaciones-MMP/`

MMP es una empresa ficticia creada para un proyecto académico. Las imágenes utilizadas son ilustrativas y no muestran maquinaria real de la empresa.
